# Condition Tracker PWA

個人用・無料運用を前提にした静的PWAです。

## 入っている機能
- 「寝る」「起きた」ボタンで睡眠時間を自動計算
- 食事文章入力からカロリー・PFCを概算
- 運動種目・時間・メモの記録
- 100点満点コンディションスコア
  - 睡眠 40点
  - 食事 35点
  - 運動 25点
- 未入力項目を0点扱いしない暫定スコア
- 7日間履歴
- 端末内IndexedDB保存
- JSON / CSVバックアップ
- PWA（ホーム画面追加・オフラインキャッシュ）

## まずPCで確認
`index.html` を直接開くと画面は確認できます。
ただしService Worker / PWAインストールはHTTPS配信時のみ正常動作します。

## 無料でiPhoneから使う方法
静的ホスティングにこのフォルダをそのまま配置してください。
Cloudflare Pages / GitHub Pages / Netlify等で利用できます。

iPhoneではSafariでURLを開き、
「共有」→「ホーム画面に追加」
でアプリのように起動できます。

## 注意
- 食事解析はAI APIではなく、`app.js` 内のローカル食品辞書で動作します。
- 外食・調理法・分量差による誤差があります。
- 食品を増やす場合は `FOOD_DB` に追加してください。
- Safariのサイトデータを削除するとIndexedDBも消える可能性があるため、定期的にJSONバックアップを推奨します。
- HealthKit歩数連携はWeb/PWAでは直接実装していません。
